# Space Wallpaper Studio — Android-проект

Исходный проект редактора космических обоев для Android.

## Возможности проекта
- выбор изображения из галереи;
- предпросмотр с приближением и поворотом;
- яркость, контраст, насыщенность и чёрно-белый режим;
- размытие предпросмотра на Android 12+;
- экспорт JPEG в вариантах 1080p / 2K / 4K;
- установка изображения на главный экран, экран блокировки или оба экрана;
- анимированный демонстрационный предпросмотр пяти вариантов перехода и настройка скорости.

## Важно о переходе при разблокировке
Android обычно не разрешает обычным приложениям заменять системную анимацию перехода с экрана блокировки на главный экран. Поэтому приложение показывает и настраивает предпросмотр эффектов, но не может гарантировать их применение при настоящей разблокировке. Это зависит от версии Android, производителя и лаунчера.

## Самый простой способ собрать APK через Android Studio
1. Установи Android Studio на компьютер: https://developer.android.com/studio
2. Распакуй архив.
3. В Android Studio выбери **Open** и укажи папку `SpaceWallpaperStudio` (внутри неё находятся `settings.gradle.kts` и `app/`).
4. Дождись завершения Gradle Sync. При запросе установи Android SDK 35 и JDK 17.
5. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Готовый файл будет здесь: `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка APK в облаке через GitHub Actions
В проект добавлен workflow `.github/workflows/build-apk.yml`.
1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в него содержимое папки `SpaceWallpaperStudio` (не сам ZIP-файл).
3. Открой вкладку **Actions** репозитория.
4. Выбери workflow **Build Android APK** и нажми **Run workflow** (либо дождись автоматической сборки после загрузки в ветку `main`).
5. После успешной сборки открой запуск workflow и скачай артефакт `SpaceWallpaperStudio-debug-apk`. Внутри будет `app-debug.apk`.

## Технические требования
- Android Studio с поддержкой Android Gradle Plugin 8.7.3;
- JDK 17;
- Android SDK 35;
- минимальная версия Android — 10 (API 29).

APK, собранный как `debug`, предназначен для установки и тестирования. Для публикации в Google Play потребуется отдельная release-сборка и подпись ключом.
